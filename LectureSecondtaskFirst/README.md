# Лекция 2: Класс FooString

## Задача
Реализовать собственный строковый класс `FooString` с ручным управлением памятью.

## Файлы
- `class.h` — объявление класса.
- `class.cpp` — реализация.
- `foo.cpp` — демонстрационная программа.
- `tests.cpp` — модульные тесты.

## Возможности класса
- конструктор от `char*`;
- конструктор копирования (глубокое копирование);
- деструктор;
- оператор присваивания с защитой от самоприсваивания;
- `show()` — вывод строки;
- `length()` — длина строки **включая `'\0'`**;
- `compare(FooString)` и `compare(const char*)` — сравнение;
- `add(FooString)` и `add(const char*)` — добавление в конец.

## Сборка и запуск

Демонстрация:
```bash
g++ -std=c++11 -Wall -Wextra -o foo foo.cpp class.cpp
./foo
```

Тесты:

```bash
g++ -std=c++11 -Wall -Wextra -o tests tests.cpp class.cpp
./tests
```

Ожидаемый результат тестов:

```text
All tests passed!
```

Пример работы foo.cpp

```text
5
Проверка безопасности копирования:
Строка = bark
копия строки с точкой = bark.
```

length() возвращает strlen(buf) + 1, поэтому для "bark" получается 5.
