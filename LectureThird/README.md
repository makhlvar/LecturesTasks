# Лекция 3: Конвертер текстовых вопросов в формат GIFT

## Задача
Написать программу, которая преобразует текстовый формат вопросов в формат **GIFT** (используется в Moodle).

## Файлы
- `main.cpp` — исходный код.
- `1.txt` — пример входного файла.
- `1.gift` — пример выходного файла.

## Входной формат
Пример `1.txt`:

```text
1. Какая утилита используется обычно для сборки 
майнлайн ядра Linux?
- Cmake
+ Make 
- Gradle
- Maven
- Basel

2. Какая утилита используется обычно для сборки 
майнлайн ядра Linux?
- Cmake
+ Make
- Gradle
- Maven
- Basel

EOF
```

Правила:

· строка вопроса заканчивается символом ?;
· неверный ответ начинается с -;
· правильный ответ начинается с +;
· между вопросами — пустая строка;
· конец файла обозначается строкой EOF.

Выходной формат

Пример 1.gift:

```text
1. Какая утилита используется обычно для сборки 
майнлайн ядра Linux?{
~ Cmake
= Make 
~ Gradle
~ Maven
~ Basel
}

2. Какая утилита используется обычно для сборки 
майнлайн ядра Linux?{
~ Cmake
= Make
~ Gradle
~ Maven
~ Basel
}
```

Соответствия:

· ? в конце вопроса → добавляется {;
· - → ~;
· + → =;
· пустая строка → }.

Сборка и запуск

```bash
g++ -std=c++11 -Wall -Wextra -o gift_converter main.cpp
./gift_converter
```

По умолчанию программа:

· читает 1.txt;
· создаёт 1.gift.

Имена файлов заданы в main():

```cpp
process("1.txt", "1.gift");
```

Известные ограничения

· Имена файлов не передаются через аргументы командной строки.
· Нет проверки, открылись ли файлы.
· Нет поддержки нескольких правильных ответов.
· Нет экранирования специальных символов GIFT.
· { добавляется без пробела: Linux?{ вместо Linux? {.
· При пустой строке возможен выход за границы массива в s[s.length() - 1].
